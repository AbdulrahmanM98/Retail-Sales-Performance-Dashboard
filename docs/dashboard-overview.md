# Dashboard overview

## Business question

How can a retail team review sales performance across locations, products and months without inspecting individual sales lines?

## Audience and analytic scope

The dashboard is a self-directed learning/portfolio build using **synthetic retail data** for **45 illustrative Jeddah branches**, June through August 2026. It was inspired by multi-branch retail operations; it is **not** an official employer dashboard.

## Report visuals

Based on the supplied Power BI report's visual definitions, the page uses:

- KPI cards for sales, transaction volume, quantity and average transaction value.
- A time-based sales trend.
- Sales by product category.
- Branch comparison and top performers.
- Text-based insights for best branch, lowest branch and trend.
- Month selection and context-sensitive comparative indicators.

## Analysis workflow

1. Start from an anonymized/synthetic retail-sales workbook.
2. Organize transactional and descriptive tables and a calendar.
3. Create DAX measures.
4. Build KPI cards and charts by branch, category and time.
5. Add filter controls and dynamic insight measures.
6. Test slicer interactions and month-to-month comparisons.
